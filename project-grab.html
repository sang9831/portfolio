GRAB

한정 수량을 정해진 시간에 판매하는 DROP 커머스입니다. AIBE7 데브코스 파이널 프로젝트로 4인 팀원들과 함께 진행했습니다.

기술 스택

Java 17, Spring Boot, Spring Security, JWT, PostgreSQL, Redis, Docker, GitHub Actions, Nginx, k6, Prometheus/Grafana, AWS EC2

담당 부분

  • 판매자 등록·재신청 API 및 국세청 사업자등록 상태조회 연동
  • 운영자 판매자 심사(승인·반려) API 및 판매자 대시보드(요약, 통계, 주문 목록·상세) 구현
  • 배송 처리 및 배송 단계 전환 로직, WISH DROP 판매 임박·취소 메일 알림
  • Redis를 Aiven Valkey(TLS)로 전환, EC2 CD 및 Nginx Blue/Green 배포 구성
  • k6 기반 동시 주문·드롭 오픈 스파이크 부하테스트, Prometheus/Grafana 모니터링 구축
