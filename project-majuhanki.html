마주한끼

지역·시간·식사 취향 기반 실시간 1:1 식사 매칭 서비스입니다.

기술 스택

Java 17, Spring Boot, Spring Security, JPA/Hibernate, WebSocket/STOMP, Supabase PostgreSQL(PostGIS), Vanilla JS/Vite

담당 부분

  • Spring Security + JWT 인증 체계 설계·구현, Google OAuth2 소셜 로그인, 토큰 자동 재발급
  • WebSocket/STOMP 기반 실시간 채팅방 기능을 처음부터 설계·구현 (메시지 검증, 전송 속도 제한, 접근 제어)
  • 사용자 선호 지역 등록 및 카카오맵 위치 선택 UI, 지도 렌더링 UX 개선
  • 마이페이지 신규 제작(선호 위치, 식사 성향 테스트), 후기 작성·재매칭 지수 표시 기능
  • Swagger API 문서화, ERD 작성, 트러블슈팅·WBS 문서 작성
