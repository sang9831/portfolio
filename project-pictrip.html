PicTrip

사진 한 장에서 여행지를 찾고 AI로 국내 여행 일정을 생성하는 서비스입니다.

기술 스택

Node.js, Express, Google Gemini, Groq, LangChain, Kakao Maps/Local API, Google Places API, Supabase

담당 부분

  • 이미지 기반 여행지 추천 기능 설계·구현 (위치 추정, 분위기 분석, 이미지 압축 및 힌트 모순 검증)
  • 추정 위치·추천지 카카오맵 API 연동, 위치/힌트 불일치 시 선택 UI 제공
  • AI 추천 장소 환각 현상 해결 및 카카오 로컬 API 기반 장소 검증 로직 작성
  • Groq 연동 및 에러 발생 시 대체 모델 fallback 로직 구현
